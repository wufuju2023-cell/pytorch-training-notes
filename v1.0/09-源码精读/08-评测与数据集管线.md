## 1. 指标定义（本系列统一口径）

**【注 SRC8.1.1｜R-SRC8.1.1】（指标定义：solve@B / pass@k / 校准）**

- **solve@B（按搜索预算的成功率）**：对每题跑 B 次 MCTS 模拟，统计“在 ≤t 次迭代内找到 proof”的比例。实现：`prover_eval.compute_success_rate_by_simulations`（`prover_eval.py:103`），阈值 `[8,16,32,64,128,256,512,1024,2048]`（≤num_simulations），`solved_at_t` 要求 `proof_tree is not None and num_iterations <= t`（`:118-123`）。
- **pass@1（贪心）**：`inference_v1/generate_pass1.py`（容器 Qwen，见 02 篇）与 `prover_eval` 的默认评测均属此类。
- **pass@k / 多次采样**：`inference_v1/pass48.py`（48 采样，见 02 篇）、nanoproof 的 `Engine.generate(num_samples=…)`。
- **tactic 准确率**：`policy_eval.eval_tactic_accuracy`（`policy_eval.py:172`）——`full_acc`（所有非 mask token 全对）、`first_token_acc`、`first_token_entropy`、`all_tokens_entropy`。
- **critic 校准**：`policy_eval.eval_critic_errors`（`policy_eval.py:42`）——64 桶上的 `argmax_mse`、`soft_mse`（softmax 期望）、`entropy`，并输出 `y_true/y_pred` 供混淆矩阵（sft.py `:338` 画 wandb）。
- **价值头离线指标**：`train_value_head.py:metrics`（nll/accuracy/expected-derived MAE/within-two/pearson/深度分桶）与 `within_root_order_accuracy`（同树排序）；见 05 篇。

## 2. `scripts/prover_eval.py`（702 行）——独立 prover 评测 ★

**【代码 SRC8.2.1｜Cd-SRC8.2.1】（`prover_eval.py`：独立 prover 评测）**

- 用与 RL 相同的 `ProverWorker` + `setup_distributed_inference`（`:546`），多模型顺序评测。
- `merge_continue_results`（`:65`）：把 `--continue` 之前成功的条目并回（on-disk `proof` → live `proof_tree`），使 summary 覆盖整个基准。
- `compute_success_rate_by_simulations`（`:103`）：上面的 solve@B。
- `resolve_run_dir_models`（`:128`）：`--run-dir` 展开 `model_*.pt` 的顺序为 **last, first, 4 的倍数, 2 的倍数, 其余**，使中断的 sweep 仍两端锚定、逐级填充（`:161-166`），并可自动把“有错误的既有结果”当作隐式 `--continue`（`:484-500`）。
- 数据集：`minif2f`（`split=valid/test`）、`proofnet`、`leanworkbook`（无 test split，`:330`）；`--max-theorems`、`--num-simulations 512`、`--num-sampled-tactics 6`、`--first-token-occurrences-cap 2`、`--max-gen-tokens 24`、`--disable-solvers`；评测把 `verify_timeout` 覆盖为 30s（`:303`）。
- 结果落盘：`save_eval_results(...)` 写 per-(model,dataset) 的 `theorems.jsonl`/`summary`（`nanoproof/checkpoints.py:170-281`）。
- `print_results`（`:169`）：成功率、solved/total、errors，以及 solve@B 分解。
- 与 `scripts/run_train.py`：SFT 之后自动跑 `prover_eval.py --datasets minif2f`（04 篇 §14）。

## 3. `scripts/policy_eval.py`（353 行）——策略/ critic 指标

**【代码 SRC8.3.1｜Cd-SRC8.3.1】（`policy_eval.py`：策略 / critic 指标）**

- `_compute_entropy`（`:27`）：`H=-Σ p log p`。
- **`eval_critic_errors`（`:42`）**：
  - 只处理含 `<|value|>` 的行（`:84-88`），在 value 位置取 logits（`:93-96`）；
  - 64 个 bin token 的 logits（`:99`）→ argmax/softmax 期望（`:100-105`）；
  - 指标：`argmax_mse`、`soft_mse`、`entropy`、`y_true/y_pred`（1..64）；
  - DDP：数值和 `all_reduce(SUM)`（`:131`），`y_true/y_pred` `all_gather_object`（`:142-145`）。
- **`eval_tactic_accuracy`（`:172`）**：
  - 跳过含 `<|value|>` 的行（`:203`）；
  - `full_acc`（所有非 mask token 全对，`:219-221`）、`first_token_acc`（首个非 mask token，`:224-230`）；
  - `first_token_entropy`、`all_tokens_entropy`（仅 mask 位置，`:236-242`）；DDP 归约（`:245-257`）。
- CLI `_main`（`:289`）：加载模型 + `leantree_transitions(split)` + `sft_data_generator`，打印全部指标；被 `sft.py`、`rl.py` 复用（它们 import `eval_tactic_accuracy/eval_critic_errors`）。

## 4. 数据集加载（`nanoproof/nanoproof/data/bench/**`）

**【代码 SRC8.4.1｜Cd-SRC8.4.1】（数据集加载：miniF2F / ProofNet / RL 数据）**

- `common.py`：`BenchTheorem(source, dataset, id)`（`:17`）——`source` 是可直接喂给 REPL `proof_from_sorry` 的 Lean 源（含 `open`/辅助 `def`，但**不含 `import`**，import 在服务端进程级一次性加载）；各数据集 preamble（`MINIF2F_PREAMBLE`/`LEANWORKBOOK_PREAMBLE`/`DEEPSEEK_PROVER_PREAMBLE`，`:36-48`）。
- `minif2f.py`：从 `google-deepmind/miniF2F` 下载 `Valid.lean`/`Test.lean`（`:23`）；解析出 theorem 段落（`:72-88`），对 test 的两个已填证明定理做 `sorry` 补丁（`:60-70`）；断言 valid=256、test=244（`:92-95`），id 取自 `theorem <name>`（`:35, 97-103`）；返回 `MINIF2F_PREAMBLE + source`（`:105-108`）。
- `proofnet.py`：下载 `proofnet.jsonl`（`:25`）；把上游 `formal_statement` 统一成 `:= by\n  sorry`（`:69-78`），`_strip_imports`（`:49`）剔除 import，per-theorem header 作为 preamble（`:79-81`）；按 `split` 过滤，断言唯一 `sorry`、唯一 id（`:83-88`）。
- `data/rl/**`：`numinamath.py`、`leanworkbook.py`、`deepseek_prover.py` 提供 RL 采样数据集（带 Lean 版本 whitelist，`data/whitelists/*.whitelist.v4.27.0.json`）；`check_init.py` 读 `lean-toolchain` 决定 whitelist 并做“能否初始化为 sorry 证明”的检查。
- `data/pretrain/nemotron_dataloader.py`、`data/midtrain/leangithubraw.py`、`data/sft/leantree.py`：预训练/中训/SFT 数据（04 篇）。
