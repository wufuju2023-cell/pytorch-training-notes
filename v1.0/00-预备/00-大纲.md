## 2. 各章条目清单（主题级；具体编号由各章作者按规范分配）

### PY1 · Python 语言 I（doccode PY1，notebook N-18，代码 F-pre-py1）

- 解释器与执行模型：源码 → 字节码 → 求值循环（对照编译/链接）；REPL、脚本、模块三种入口；`__pycache__`。
- 名字绑定与对象模型：名字是绑定不是盒子（对照 C 变量/指针）；引用计数与 GC 概览；`id`/`is`/`==`；可变与不可变。
- 内置类型：`int/float/bool/complex/str/bytes/None`；`list/tuple/dict/set/frozenset`；插入序、哈希约束；切片语义（步长、负索引、拷贝 vs 视图）。
- 控制流：`if/for/while/match`、`for-else`、海象 `:=`；真值测试规则。
- 函数：位置/关键字/默认参数（可变默认值陷阱）、`*args/**kwargs`、只关键字参数、LEGB 作用域、闭包与 `nonlocal`。
- 推导式与生成器表达式；迭代协议初识（与 PY2 链接）。
- 「来源与许可」小节；自测若干（Ex）。

### PY2 · Python 语言 II（doccode PY2，notebook N-19，代码 F-pre-py2）

- 类与实例：`__init__`/`self`/类属性 vs 实例属性（对照 struct + 成员函数）；继承与 MRO 简介。
- 数据模型/魔术方法：`__repr__/__str__/__len__/__getitem__/__iter__/__eq__/__hash__/__enter__/__exit__`；运算符重载对照 C++。
- 属性：`property`、描述符概念、`__slots__`（对照内存布局）。
- `dataclass`、`typing`（`Optional/Union/Sequence/Mapping/Protocol`）、`enum`。
- 异常模型：`try/except/else/finally`、异常层级、`raise ... from`、EAFP vs LBYL（对照 C 错误码）。
- 上下文管理器（对照 RAII）与 `with`；`contextlib`。
- 装饰器：函数装饰器、带参装饰器、`functools.wraps/lru_cache`；高阶函数 `map/filter/sorted(key=)`。
- 迭代器与生成器：`yield`、惰性求值、`itertools` 常用件；读懂本仓 `data.py` 的生成器用法（`【…】` 引用）。
- 模块与包：`import` 机制、`__name__ == "__main__"`、相对导入、`sys.path`；与 C 头文件/链接的对照。
- 「来源与许可」；自测若干。

### PY4 · NumPy 与张量思维（doccode PY4，notebook N-21，代码 F-pre-py4）

- `ndarray`：shape/dtype/axis 语义；strides 与视图/拷贝（对照数组指针算术）。
- 索引：基本切片、花式索引、布尔掩码；赋值语义。
- 广播：严格规则（右对齐、1 可扩、缺失维补 1）+ 反例。
- 向量化：把双层循环改写成矩阵乘/广播；`einsum` 初识。
- 归约与轴：`sum/mean/max` 的 axis 参数；`keepdims` 与广播配合。
- 随机数：`Generator`/`default_rng`、种子与并行；与 PyTorch 随机源的对应关系。
- 线性代数：`matmul/@`、`linalg` 常用函数；为 PY5 铺垫。
- 「来源与许可」；自测若干（含把朴素实现向量化并做基准）。

### PY5 · PyTorch 从零（doccode PY5，notebook N-22，代码 F-pre-py5）

- `Tensor`：构造、dtype/device、与 numpy 互操作（`from_numpy`/`.numpy()`）、拷贝语义。
- 形状操作：`view/reshape/permute/transpose/contiguous`、`unsqueeze/squeeze`、广播；与 PY4 对照。
- autograd：计算图、叶子/非叶子、`requires_grad`、`backward()`、`.grad`、`detach/no_grad`、`retain_graph`、梯度累加与 `zero_grad`。
- `nn.Module`：参数注册、`state_dict/load_state_dict`、`train/eval`、模块嵌套；与【定义 1.1.3】MLP 对照。
- 损失与优化器：`nn.CrossEntropyLoss/MSELoss`、`SGD/Adam`；学习率与参数组。
- 数据管线：`Dataset`/`DataLoader`（batch/shuffle/collate/num_workers）、与【定义 1.2.4】经验风险对照。
- 训练循环：标准五步；保存/加载 checkpoint；AMP/`GradScaler` 初识。
- 常见错误诊断：in-place on leaf、shape 不匹配、device 混用、忘记 `zero_grad`、`eval` 未生效。
- 「来源与许可」；自测若干（含手写一个线性回归与两层 MLP 训练闭环）。

### PY6 · PyTorch 进阶与生态（doccode PY6，notebook N-23，代码 F-pre-py6）

- 与 from_scratch 代码的对照表：同一功能的两种写法（引用 `F-b0x-*`）。
- 「来源与许可」；自测若干（含读懂 `F-b04-value_head_api` 的调用链并标注对象来源）。
