## 6.1 为什么初始化决定训练成败

反向传播的梯度是许多雅可比矩阵的乘积。若每层把方差放大或缩小一个固定因子，深层网络的激活与梯度会指数爆炸或消失：

$$
\text{Var}\!\left[ x^{(l)} \right] \sim \prod_{k=1}^{l} c_k .
$$

初始化的目标（dynamical isometry）是让 $c_k \approx 1$。

### 6.1.1 方差传播推导

设 $z^{(l)} = W^{(l)} x^{(l-1)}$，$W$ 元素独立、均值 0、方差 $\sigma_w^2$，$x$ 分量独立、均值 0、方差 $\sigma_x^2$，且相互独立。则

$$
\mathrm{Var}\!\left[ z_i^{(l)} \right]
= \sum_{j=1}^{n_{l-1}} \mathrm{Var}\!\left[ W_{ij} \right] \mathrm{Var}\!\left[ x_j^{(l-1)} \right]
= n_{l-1} \sigma_w^2 \sigma_x^2 .
$$

要维持方差，需 $n_{l-1}\sigma_w^2 = 1$。同时考虑反向需 $n_l\sigma_w^2 = 1$，折中得 $\sigma_w^2 = 2/(n_{l-1}+n_l)$（Xavier）。ReLU 丢弃一半激活，故加倍：$\sigma_w^2 = 2/n_{l-1}$（Kaiming）。

## 6.2 常见初始化

| 方案 | 方差 | 适用 |
| --- | --- | --- |
| Xavier 正态 | $2/(n_{in}+n_{out})$ | tanh / sigmoid |
| Xavier 均匀 | $\mathrm{Unif}(\pm\sqrt{6/(n_{in}+n_{out})})$ | tanh / sigmoid |
| Kaiming 正态 | $2/n_{in}$ | ReLU / relu^2 |
| Kaiming 均匀 | $\mathrm{Unif}(\pm\sqrt{6/n_{in}})$ | ReLU |
| 零初始化 | 0 | 残差投影、LoRA 的 $B$ |

`nanoproof` 用均匀分布，范围 $\pm\sqrt{3}\,d_{\text{model}}^{-1/2}$（方差 $1/d_{\text{model}}$），MLP 第一矩阵再乘 0.4：

```python
s = 3**0.5 * n_embd**-0.5
torch.nn.init.uniform_(block.attn.c_q.weight, -s, s)
torch.nn.init.uniform_(block.attn.c_k.weight, -s, s)
torch.nn.init.uniform_(block.attn.c_v.weight, -s, s)
torch.nn.init.zeros_(block.attn.c_proj.weight)      # 残差投影零初始化
torch.nn.init.uniform_(block.mlp.c_fc.weight, -s * 0.4, s * 0.4)
torch.nn.init.zeros_(block.mlp.c_proj.weight)
```

### 6.2.1 残差投影为什么零初始化

在 $x' = x + f(x)$ 中，若 $f$ 输出初始化方差非 0，激活方差会随层数累积放大。把每个残差分支的最后一层（`c_proj`）初始化为 0，使每个 block 初始化时是恒等映射，方差才能跨层守恒。

### 6.2.2 逐层可学习标量

```python
self.resid_lambdas.data[i] = 1.15 - (0.10 * i / max(n_layer - 1, 1))
self.x0_lambdas.data[i]    = 0.20 - (0.15 * i / max(n_layer - 1, 1))
```

即浅层残差权重略大于 1（1.15），深层降到 1.05；初始嵌入贡献从 0.20 降到 0.05。浅层更"记忆"输入、深层更"抽象"。

## 6.3 LoRA 的初始化：`init_lora_weights=True`

LoRA 把权重更新分解为低秩乘积：

$$
W = W_0 + \Delta W = W_0 + \frac{\alpha}{r} B A, \qquad A \in \mathbb{R}^{r \times d_{in}}, \quad B \in \mathbb{R}^{d_{out} \times r}, \quad r \ll \min(d_{in}, d_{out}) .
$$

`peft` 默认 `init_lora_weights=True`：$B$ 零初始化、$A$ 随机（Kaiming）。于是 $\Delta W = \frac{\alpha}{r} B A = 0$，模型行为与 $W_0$ 完全一致，微调从预训练模型平滑出发。

第一步梯度对 $B$ 非零（$g_B = g (Ax)^\top$），对 $A$ 为零（$g_A = B^\top g\, x^\top = 0$），因此 $B$ 先学方向、$A$ 随后跟进。秩的选择与 $\alpha$ 缩放见关联的 LoRA 文档第 02 篇。

## 6.4 学习率调度

### warmup

初期优化器状态未稳、损失面陡，大学习率易发散。warmup 线性升至峰值：

$$
\eta_t = \eta_{\max} \cdot \frac{t}{T_{\text{warm}}}, \qquad t < T_{\text{warm}} .
$$

`common.py::get_lr_multiplier`：

```python
if args.warmup_ratio > 0 and progress < args.warmup_ratio:
    return (progress + 1e-8) / args.warmup_ratio
```

### 常量 + 线性 warmdown

$$
m(p) =
\begin{cases}
p / p_{\text{warm}}, & p < p_{\text{warm}}, \\
1, & p_{\text{warm}} \le p \le 1 - p_{\text{warmdown}}, \\
(1 - d) + d\, f, & d = \dfrac{p - (1 - p_{\text{warmdown}})}{p_{\text{warmdown}}},
\end{cases}
$$

其中 $f = \text{final\_lr\_frac}$。余弦调度：$\eta_t = \eta_{\min} + \frac{1}{2}(\eta_{\max}-\eta_{\min})(1+\cos(\pi t/T))$。`pretrain.py` 用余弦调度权重衰减：

```python
def get_weight_decay(it):
    return weight_decay_scaled * 0.5 * (1 + math.cos(math.pi * it / num_iterations))
```

### init_lr_frac

```python
for group in optimizer.param_groups:
    group["lr"] = group["lr"] * args.init_lr_frac
    group["initial_lr"] = group["lr"]
```

`rl.py` 默认 `init_lr_frac=0.02`（保守），`sft.py` 默认 `0.8`——RL 阶段更怕策略崩塌。

## 6.5 梯度范数与训练健康

梯度范数 $\lVert g \rVert = \sqrt{\sum_p \lVert g_p \rVert^2}$ 是核心健康指标：

- **持续增大**：学习率过大或初始化不当，逼近发散；
- **持续极小**：梯度消失或 loss mask 错误；
- **周期性尖峰**：离群样本或长序列。

配套：梯度裁剪、有限性断言（`value_head.py`）、warmup 让初期范数与学习率同步增长。

---

## 6.6 批大小、宽度与学习率

- **线性规则** $\eta \propto B$：小批噪声主导区间成立；
- **开方规则** $\eta \propto \sqrt{B}$：更稳健，`nanoproof` 采用：

```python
batch_ratio = total_batch_size / B_REF
batch_lr_scale = batch_ratio ** 0.5
```

模型宽度缩放：AdamW 组再乘 $(d_{\text{model}}/768)^{-1/2}$。权重衰减按 batch 与数据量缩放：

```python
weight_decay_scaled = (
    args.weight_decay * math.sqrt(total_batch_size / B_REF) * (D_REF / target_tokens)
)
```

## 6.7 一段可运行的实验

```python
import math, torch

def var_of_layer(din, dout, init, n=2000):
    torch.manual_seed(0)
    W = torch.empty(dout, din)
    if init == "default":
        torch.nn.init.kaiming_uniform_(W, a=math.sqrt(5))
    elif init == "xavier":
        torch.nn.init.xavier_uniform_(W)
    else:
        W.normal_(0, 1.0)
    x = torch.randn(n, din)
    return float((x @ W.T).var())

for init in ("default", "xavier", "naive"):
    print(init, var_of_layer(512, 512, init))

def lr_multiplier(p, warm=0.05, warmdown=0.3, final=0.1):
    if p < warm:
        return p / warm
    if p <= 1.0 - warmdown:
        return 1.0
    d = (p - (1.0 - warmdown)) / warmdown
    return (1 - d) + d * final

print([round(lr_multiplier(p), 3) for p in (0.0, 0.05, 0.5, 0.8, 1.0)])
```

观察：naive 初始化让输出方差随宽度爆炸，Xavier/Kaiming 保持 $O(1)$。

## 6.8 小结

1. 初始化目标是逐层保持信号方差；Xavier 用于对称激活，Kaiming 用于 ReLU。
2. `nanoproof` 用均匀 $\sqrt{3/d}$ 初始化注意力、零初始化输出投影、嵌入/头分设不同 $\sigma$。
3. LoRA 用 $B=0$ 保证初始 $\Delta W = 0$，不破坏预训练权重。
4. warmup 抑制初期发散，warmdown / cosine 提升末期收敛。
5. 批大小按开方（或线性）缩放学习率；宽度按 $1/\sqrt{d}$ 缩放；weight decay 随 token 数缩放。
6. 梯度范数是训练健康的核心监控量。
