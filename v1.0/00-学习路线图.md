## 3. 阶段路线与验收

**【注 ROAD.3.1｜R-ROAD.3.1】（阶段路线与验收）**

- **Stage -1 预备篇**（`00-预备/`，N18–N23）：Python 零基础起步——PY1/PY2 语言 → PY3 工程环境 → PY4 NumPy/张量思维 → PY5 PyTorch 从零 → PY6 生态速览。验收 = 能独立跑通 `01-基础/` 全部代码与 N01–N08；详见 [`00-预备/00-大纲.md`](00-预备/00-大纲.md)。
- **Stage 0 环境**：Python/PyTorch 环境、`datasets/README.md`、`tiny/` 配置；验收 = 能跑通 N01。
- **Stage 1 基础**（`01-基础/`，N01–N08）：反向传播 → 优化器 → Attention/Transformer → 分词器 → 训练循环 → 初始化与调度。验收 = 自己搭的 tiny GPT 能过拟合小语料并生成文本。
- **Stage 2 预训练**（`02-预训练/`，N09）：验收 = 小语料上 loss 稳定下降，能对照 nanoproof 的 pretrain/midtrain 讲清差异。
- **Stage 3 SFT**（`03-SFT/`，N10）：验收 = 造出 (state → tactic) 指令集并完成 token-masked 微调。
- **Stage 4 价值头**（`04-价值头/`，N11）：验收 = scalar 与 64-bin 价值头训练 + 校准曲线/ECE。
- **Stage 5 LoRA**（`05-LoRA/`，N12）：验收 = 手写 LoRA 注入 vs PEFT/QLoRA 参数量与显存对比。
- **Stage 6 后训练 RL**（`06-RL-RLVR/`，N13–N14）：验收 = 最小 GRPO 在可验证奖励上收敛，能逐项对上 `/ttt_step`。
- **Stage 7 MCTS+V1**（`07-MCTS+V1/`，N15–N16）：验收 = 极简 PUCT 树 + 价值头闭环可解小任务；与 V1 流程图逐点对齐。
- **Stage 8 V1-1**（`08-V1-1/`，N17）：验收 = tool-calling agent 跑通一次多步闭环。
- **Stage 9 源码精读**（`09-源码精读/`）：验收 = 能指出每个 GPU 版本"想改某行为应动哪个函数"。

## 4. 规模与运行环境

**【注 ROAD.4.1｜R-ROAD.4.1】（规模与运行环境）**

- 从零模型：1–20M 参数（`tiny/config_gpt_micro.json`、`config_gpt_tiny.json`）；CPU 可跑，云 GPU 更快。
- API 版本：HF 小基座 + LoRA / 4bit QLoRA。
- 云 GPU 执行：AMD ROCm，统一以 root 运行（`zhai` 用户无 `/dev/kfd` 权限）；notebook 内用 `device = "cuda" if torch.cuda.is_available() else "cpu"` 自适应。
- Colab：每个 notebook 均可直接上传运行（含 `!pip install` 单元），CPU 也给出可行步数。

## 7. 使用建议

**【注 ROAD.7.1｜R-ROAD.7.1】（使用建议）**

1. 按 Stage 0→9 顺序；每阶段先读 `01-原理.md`，再读 `code/from_scratch/`，然后跑 notebook，最后读 `code/with_api/` 与 `09-源码精读/` 对应篇。
